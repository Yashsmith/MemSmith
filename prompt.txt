TermCN added Dither Charts for OpenTUI

• axes
• grids
• legends
• tooltips
• grouped and stacked data
• bloom effects

• keyboard inspection

This was added in July 2026. 

That's almost exactly the visualization language you're describing.

How I'd connect Python and TypeScript

I would NOT have TypeScript constantly call Python functions.

Use an event protocol.

Something like:

Python
   │
   │ JSON events
   ▼
WebSocket / local IPC
   │
   ▼
TypeScript TUI
   │
   ├── state
   ├── animations
   ├── charts
   └── rendering

For example Python emits:

{
  "event": "feature_engineering",
  "progress": 0.73,
  "features_created": 61
}

TUI turns that into:

FEATURE ENGINEERING

61 / 84

████████████████░░░░░

GENERATING:
customer_tenure_bucket
monthly_charge_ratio
support_frequency
contract_risk_score

Then another event:

{
  "event": "model_metrics",
  "auc": 0.912,
  "f1": 0.834,
  "recall": 0.871
}

The graphs update immediately.

OpenTUI isn't just a collection of box drawing utilities.

The native core gives you a component tree, layout, rendering and incremental updates, while TypeScript gives you the application layer.

You probably don't even need 3D for your project.

Python ML backend + TypeScript/OpenTUI/TermCN visualization frontend is the architecture I'd choose.

And your project is actually an unusually good candidate for this because churn prediction naturally gives you streaming data, feature importance, temporal trends, model metrics, probabilities, pipeline stages and explainability, all of which can become live visual elements.
